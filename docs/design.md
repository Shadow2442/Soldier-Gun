# Soldier Gun Design Notes

## Pillars

- Fast and readable: the player should always understand where danger is and where power is.
- Aggressive but fair: dense action without cheap hits.
- Short-burst mastery: every run should reward routing, timing, and confidence.
- Original identity: inspired by the Soldier line, but not a clone.

## Visual direction

- Internal resolution: `320x240`
- Sharp sprite silhouettes
- Bright weapon colors with strong contrast against backgrounds
- Layered sci-fi stages with restrained parallax
- Explosions that read clearly without obscuring bullets

## Feel targets

- Locked `60 FPS`
- Snappy movement with minimal acceleration smoothing
- Immediate shot response
- Bombs as both panic buttons and tempo tools
- Bullets must stay readable even in dense scenes

## Initial game modes

- Arcade: a full stage progression mode
- Caravan 2: a two-minute score attack
- Caravan 5: a five-minute score attack

## Core systems

- Color-coded weapon families with distinct coverage roles
- Score value tied to wave efficiency and survival
- Bosses built around readable phases, not random spam
- Recovery paths that help a damaged run come back without removing tension
